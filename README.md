# GPT-Plus 多用户管理控制台

基于 Node.js + Express + SQLite + Vue3 的多用户 GPT 账号 / 邮箱管理系统，克莱因蓝企业控制台风格。

**本仓库是公开展示仓**（欢迎 Star）。完整业务源码在私有仓，路人 `git clone` 这里拿不到可运行的全部代码。

## 能做什么

- 控制台：账号 / 邮箱统计、套餐到期、流水线状态
- 账号管理 GB / GC：注册、提链、支付墙、拿 RT
- 账号同步：普通号与 PLUS 上架记录
- 邮箱、域名、运行日志、个人设置与套餐配置
